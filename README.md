# Public project page

Static, self-contained project page for the capability-laundering paper.
`index.html` + `figs/` (PNGs copied from `paper/figs/`) — no build step, no
external dependencies. Drop the directory into any static host (GitHub Pages
public repo, Azure Static Web Apps, etc.).

## Content policy

The page follows the paper's release stance (`paper/ethical_considerations.tex`):
methodology, results, figures, and defensive implications are public; the
laundering implementation, automation code, and operational prompt details are
not on the page and must not be added to it. Figures are the paper's own
rendered PNGs.

## Updating figures

Regenerate the result plots, then sync the page assets:

```bash
python scripts/plot_results_figure.py
python scripts/style_page_figures.py
```

The sync step copies the four generated cyber figures from `paper/figs/` and
maps the two legacy CBRN raster figures to the page's shared blue, orange,
teal, purple, and danger-red palette without changing their data or geometry.
